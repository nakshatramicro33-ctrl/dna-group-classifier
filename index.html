🧬 DNA Sequence Group Classifier

Machine-learning-based classification of DNA sequences into Group A or Group B

Project objective

This project tests whether a simple machine-learning model can learn patterns from labelled DNA sequences and predict the group of an unknown sequence.

Each DNA sequence is converted into numerical features: A count, T count, G count, C count, sequence length, and GC content.

Training dataset

Sequence ID DNA sequence Group

Extracted features

Sequence ID DNA sequence A T G C Length GC content (%) Group
GC content formula:
GC content (%) = ((G + C) / total sequence length) × 100

Model result

A Decision Tree classifier was trained using the six numerical features from the four labelled DNA sequences.

Training accuracy: 100%

The model correctly classified all four training sequences. However, this is training accuracy, not test accuracy. Because only four sequences were used, it does not prove that the model will correctly classify new DNA sequences.

Most useful feature

The most useful feature was the G count. Group A sequences have 2 G bases, while Group B sequences have 3 or 4 G bases. Therefore, the model learned that a higher G count is associated with Group B.

Genomics application

One application of AI and machine learning in genomics is disease-risk prediction from genetic variants. Machine-learning models can analyse patterns in DNA variants and help estimate a person’s risk of certain inherited or complex diseases.

This can support early screening, personalised prevention, and more targeted medical care. However, predictions must be validated carefully because genetics is only one factor affecting health.

Limitations of AI/ML

A major limitation is that AI/ML models depend on the quality, size, and diversity of their training data. This project uses only four DNA sequences, so the model may learn a simple rule based on G count rather than a reliable biological pattern.

If a new sequence is very different from the training data, the model may make an unreliable prediction. This is called poor generalisation. AI predictions should therefore be reviewed by experts and validated experimentally before being used for important decisions.
